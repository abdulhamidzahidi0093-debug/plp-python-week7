# Week 7 Assignment: My Notes & The Report Builder

This repository contains my Week 7 Python assignment about file handling and reading CSV data.

## Files

- my_notes.py: Creates, appends, reads, and counts notes in a text file.
- my_notes.txt: Stores my four personal programming notes.
- report_builder.py: Reads learner information, calculates results, and creates a report.
- hubs.csv: Contains learner names, hub names, and scores.
- report.txt: Contains the final learner report with pass count, fail count, and average score.
- README.md: Describes the assignment and what I learned.
